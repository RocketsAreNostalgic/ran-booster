# Security

Only the latest Beta release receives security fixes.

Report vulnerabilities through GitHub's private vulnerability-reporting form:

https://github.com/RocketsAreNostalgic/ran-booster/security/advisories/new

If that form is unavailable, open a public issue containing only a request for
confidential contact. Do not include vulnerability details, repository
credentials, webhook secrets, WordPress salts, database contents, signed URLs,
release assets, customer data, or production log extracts in a public issue.

Include the RAN Booster, WordPress, PHP, and database versions in the private
report. State which repository provider and package operation were involved,
but redact repository and site identities when they are not needed to reproduce
the problem.
