# Support

RAN Booster is currently in Beta. The latest Beta release is the supported
version.

Use the [issue chooser](https://github.com/RocketsAreNostalgic/ran-booster/issues/new/choose)
for ordinary support, reproducible non-sensitive defects, and feature requests.
There is no guaranteed response or resolution time.

Before opening an issue, gather the RAN Booster, WordPress, PHP, and database
versions. Include the repository provider and package operation involved, the
steps needed to reproduce the problem, and the expected and actual result. A
Booster support reference is useful when one is available, but remove private
repository and site identities unless they are essential to reproduction.

Do not put vulnerability details, credentials, webhook secrets, WordPress
salts, database or customer data, signed URLs, release assets, private source,
full production logs, private workbench material, or Dex identifiers in an
issue or pull request. Report vulnerabilities through the private route in
[SECURITY.md](SECURITY.md).

Reports about conduct belong through the private enforcement route in
[CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md), not through a public issue.
